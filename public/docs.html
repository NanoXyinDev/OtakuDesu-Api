Dokumentasi API

Endpoint data memakai metode GET dan mengembalikan JSON. Gunakan filter sumber di sidebar untuk melihat hanya Otakudesu, Samehadaku, atau Gabungan. API key opsional: tanpa key kamu dihitung sebagai tamu dengan batas kecil. Daftar untuk mendapat key dan batas lebih besar, lalu kirim lewat header X-API-Key. Setiap respons membawa header X-RateLimit-Limit, X-RateLimit-Remaining, dan X-RateLimit-Reset.

Cache dan header

  • Respons disimpan di memori server (dan Redis kalau dipasang) selama CACHE_TTL detik (bawaan 300). Respons dari cache membawa X-Cache: HIT.
  • Stale-if-error: kalau situs sumber error atau diblokir, data lama tetap disajikan dengan X-Cache: STALE dan "stale": true, selama umurnya kurang dari STALE_TTL.
  • Setiap respons membawa X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset, dan X-RateLimit-Role. Kalau batas terlampaui: HTTP 429 dengan Retry-After.
  • Cache-Control sengaja private, supaya CDN tidak melewati pembatas request dan cek login.
  • /stream (Otakudesu dan Samehadaku) tidak di-cache karena URL embed bisa kedaluwarsa.
  • CORS terbuka (Access-Control-Allow-Origin: *), jadi bisa dipanggil dari frontend. Kirim API key lewat header X-API-Key.
