Dokumentasi API

Semua endpoint memakai metode GET dan mengembalikan JSON. API key opsional: tanpa key kamu dihitung sebagai tamu dengan batas kecil. Daftar untuk mendapat key dan batas lebih besar, lalu kirim lewat header X-API-Key. Setiap respons membawa header X-RateLimit-Limit, X-RateLimit-Remaining, dan X-RateLimit-Reset.

Format respons

Respons sukses selalu membungkus hasil di data. Respons gagal berisi pesan yang menjelaskan masalahnya.

Kode status

Kegagalan selalu berbentuk JSON dengan status: false.

KodeArtinya

Cache dan header

  • Respons disimpan di memori server selama CACHE_TTL detik (bawaan 300). Respons dari cache membawa header X-Cache: HIT.
  • Cache-Control diatur ke public, s-maxage=300, stale-while-revalidate=60 supaya CDN seperti Vercel ikut menyimpan.
  • /api/stream tidak di-cache karena URL embed bisa kedaluwarsa.
  • CORS terbuka: Access-Control-Allow-Origin: *, jadi bisa dipanggil langsung dari frontend.

Konfigurasi server

Semua variabel opsional. Di Vercel, isi lewat Settings, Environment Variables.

VariabelBawaanFungsi
PROXY_LISTkosongDaftar proxy dipisah koma. Dipakai bergantian di setiap request. Wajib kalau situs sumber memblokir IP server.
TIMEOUT8000Batas waktu satu request ke situs sumber, dalam milidetik.
CACHE_TTL300Lama cache dalam detik. Isi 0 untuk mematikan.

STREAM_ACTIONbawaanID action admin-ajax untuk URL embed.

Kitsune API adalah proyek tidak resmi dan tidak berafiliasi dengan situs sumbernya. Gunakan dengan wajar dan hormati batas akses situs sumber.
