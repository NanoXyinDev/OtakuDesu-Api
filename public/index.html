Apa saja yang bisa diambil

Empat kelompok endpoint, dari daftar judul sampai link unduh. Klik nama endpoint untuk melihat parameter dan contoh respons.

Cari dan jelajahi

Pencarian judul, anime yang sedang tayang, yang sudah tamat, daftar A–Z, jadwal rilis mingguan, dan anime per genre.

  • /api/search
  • /api/ongoing
  • /api/complete
  • /api/anime-list
  • /api/schedule
  • /api/genres

Detail anime

Info, sinopsis, dan semua episode dalam satu respons.

  • /api/anime/{slug}

Nonton

Server mirror per kualitas, URL embed, dan episode sebelum atau sesudahnya.

  • /api/watch/{slug}
  • /api/stream

Unduh

Link per episode, batch, atau paket lengkap, dikelompokkan per kualitas.

  • /api/download/{slug}
  • /api/batch/{slug}

Siap untuk frontend

CORS terbuka, respons di-cache, dan setiap request memakai User-Agent yang berganti. Pasang proxy lewat PROXY_LIST kalau situs sumber memblokir server kamu.

Dari judul sampai link nonton dalam tiga request

Setiap langkah memakai slug dari langkah sebelumnya. Contoh di bawah memakai alamat server ini.

  1. Cari judul

    Ambil slug dari hasil pertama.

  2. Ambil detail dan episode

    Respons berisi episodes[], plus batch dan lengkap untuk unduhan.

  3. Buka halaman nonton

    Dapatkan server mirror, link unduh, dan slug episode berikutnya.

Kitsune API adalah proyek tidak resmi dan tidak berafiliasi dengan situs sumbernya. Seluruh judul, gambar, dan video milik pemegang haknya masing-masing. Gunakan dengan wajar dan hormati batas akses situs sumber.
